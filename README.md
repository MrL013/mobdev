# Лабораторная работа №1 — «Продвинутый калькулятор»

Мобильное приложение на Flutter для ввода и вычисления арифметических выражений.

## Возможности

- ввод выражений с `+`, `−`, `×`, `÷`, десятичными числами, скобками и процентом;
- правильный приоритет операций и изменение порядка вычислений скобками;
- очистка ввода, удаление последнего символа и смена знака числа;
- история последних 10 вычислений: нажатие на запись возвращает выражение для редактирования или повторного вычисления;
- память калькулятора: `M+`, `M−`, `MR`, `MC`;
- сохранение текущего выражения, истории, памяти, результата и ошибки при пересоздании интерфейса, в том числе после поворота экрана;
- понятная обработка ошибок: деление на ноль, пустое или незавершённое выражение, неверные скобки, несколько точек в числе и некорректные операторы.

## Устройство проекта

- `lib/main.dart` — запуск приложения и интерфейс: дисплей, кнопки, история, адаптивная компоновка и восстановление состояния.
- `lib/calculator/calculator_controller.dart` — состояние калькулятора и обработка действий пользователя: ввод, память, история, ошибки и сериализация состояния.
- `lib/calculator/expression_evaluator.dart` — независимая от интерфейса логика вычисления. Выражение разбирается на токены, переводится в обратную польскую запись алгоритмом сортировочной станции и вычисляется стеком.

## Тесты

- `test/expression_evaluator_test.dart` проверяет приоритеты, скобки, проценты, отрицательные и десятичные числа, а также ошибочные выражения.
- `test/calculator_controller_test.dart` проверяет память, ограничение истории десятью записями и восстановление сохранённого состояния.
- `test/calculator_widget_test.dart` проверяет пользовательский сценарий ввода выражения через кнопки и появление результата в истории.

## Запуск и проверка

```powershell
flutter run
flutter analyze
flutter test
```

Перед запуском выберите эмулятор или подключите устройство. Список доступных устройств: `flutter devices`.
